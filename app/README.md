# ArtKiddo Local app

This is the account-free composition of the public foundation. Android, iOS,
and macOS projects are versioned here; machine-specific properties, generated
artifacts, and local caches are not.

The application identifier is `ca.bencool.artkiddo.local`. This variant needs
no account, secret, endpoint, or remote adapter. A private distributed app owns
its own checkout, identifiers, and adapter composition.
